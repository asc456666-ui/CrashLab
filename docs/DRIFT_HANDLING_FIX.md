# 漂移操控与驾驶抖动修复

用户反馈：两侧气流遮挡、车辆一顿一顿、漂移容易失控。

## 复现与原因

在平地使用相同输入，比较开启和关闭旧漂移：先直行，再右转、左转，最后松开方向。覆盖普通车、星星车、跑车与 30 / 60 / 120Hz 更新。

旧版直接修改侧向速度及偏航角速度，同时大幅削弱后轮抓地，与车轮正常转向互相干扰。普通车 60Hz 测试侧滑角最高约 36.7°；车身还按原始方向输入叠加视觉旋转，左右切换单帧可跳约 16.2°。120Hz 显示直接使用 60Hz 刚体当前位置，会隔帧停住。

## 调整

- 移除漂移两侧屏幕气流、世界空间长线拖尾与对应更新逻辑。空中飞行效果保留。
- 移除强推侧向速度、强制偏航和车身假旋转。转向仍由车轮决定。
- 平滑方向输入和漂移强度，持续带油门转弯才渐进介入；高速、刹车、缺轮和腾空时减少或退出辅助。
- 根据实际侧滑角恢复后轮抓地，抑制过大的甩尾，保留轻量烟雾与提示。
- 渲染车身位置和朝向使用物理插值，四轮相对车身一起重定位；重置、传送和翻正同时清除旧插值状态，避免拉回旧位置。
- 车流轮子动画复用矩阵与向量，固定模型不再每帧重新计算包围球，减少分配与回收。

## 验证

相同连续转向测试，普通车侧滑角降至约 10.6°，60Hz 单帧姿态变化不超过约 1.6°；三款车均在松开方向后恢复，未翻覆。120Hz 的 120 帧连续驾驶检查中，至少 118 帧车身位置继续推进，而非每隔一帧停住。

45 项回归测试通过，包括三款车 × 三种刷新率、插值与传送、原有坡道飞行、地图及密码行为。浏览器另以真实键盘输入验证直行、左右转向、松开方向、无两侧气流及飞行兼容。软件渲染环境帧率不能代表手机或硬件加速浏览器的帧率。
