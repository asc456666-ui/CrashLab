# 开放驾驶游乐世界

## 内容

主地图从 600 × 600 米扩至 1200 × 1200 米，随后新增向外延伸的滨海高速和通过传送门抵达的独立小岛。保留原有区域，没有计圈、竞赛或强制完成顺序。最新内容见 [生物小岛、高速与飞跃更新](ISLAND_FLIGHT.md)。

| 区域 | 主要内容 |
|---|---|
| 云顶山地 | 三段连续爬升、转角平台、48 米山顶观景台和离山跳台 |
| 浅湾湿地 | 低抓地力泥地、可涉水浅湾、木桥、林边营地 |
| 采石工地 | 四座可翻越砂丘、可撞散货箱、吊装重物、可载车升降台及高空平台 |
| 集装箱港口 | 两侧码头、可开合桥、可爬上屋顶的集装箱、可推动货箱及可驶入仓库 |
| 天空停车楼 | 两层高架停车平台、侧坡与转向平台、屋顶跳台和落脚平台 |
| 机械游乐谷 | 三组不同高度的跳台、带真实铰链的跷跷板、可推动滚筒 |
| 滨海高速 | 长直路、岔路、跨线立交、巡游车流、飞坡和进岛光门 |
| 生物小岛 | 动物、怪兽、可倒树木、无碰撞草丛、观景坡和返回车库光门 |

另有六处原地维修站、十六处探索地标、地图区域传送、驾驶小地图与附近机关提示。探索地标记录通过现有设置存储在本机。小岛仅通过光门进出。

## 操作

- W/A/S/D 或屏幕驾驶按钮：驾驶。
- M / 右上角地图：打开地图，暂停游戏和游玩计时。
- Esc / 继续驾驶：关闭地图。
- 点击区域卡片：传送到对应入口并修复当前车辆。
- E / 靠近机关后出现的互动按钮：操作机关；重复按键不会连续触发。
- 地图底部“重置建筑”：恢复建筑和场地道具，包括机关位置；不修复或替换当前车辆，不清除探索记录。

## 建筑破坏规则

按用户要求，破坏状态在同一次应用运行中保留：换车、回主菜单后重新开始、区域传送均不恢复建筑、砖块、货物或场地机关。换车和重新开始只让原有落锤回到待用位置。

主动点击“重置建筑”才恢复建筑与场地道具；关闭并重新打开应用仍从初始场景开始。当前未实现将全部物理物体状态保存到磁盘。

## 实现与性能

- 新区域放在独立 OpenWorld 模块，复用现有车辆、物理世界和音效，不加载在线资源。
- 重复地面装饰、道路标线、树木及集装箱肋条使用实例化渲染。
- 新增活动道具最多二十个以内，升降台和桥使用运动学刚体，跷跷板使用铰链约束。
- 新通行坡道按顶面端点建模，物理与视觉使用同一旋转；停车楼转向平台保证完整车宽支撑。
- 换车时释放车辆独有渲染资源，共享玻璃和橡胶材质保留。

## 验证与限制

三十五项回归测试覆盖区域配置、坡道物理对齐、泥地抓地力、地标持久记录、机关运动、实际车辆乘升降台及停车楼上层通行、飞跃、双击油门、生物碰撞、双岛传送门、巡游、动物行为、漂移及立交两侧上桥，并覆盖此前的车辆清理、设置 / 后台密码、限时和退出修复。

浏览器验证使用实际游戏物理，检查六区入口和八段通行路线（三级山路、两层停车楼、湿地木桥、港口桥和集装箱屋顶），同时检查建筑保留 / 主动重置和横屏手机地图布局。

尚未进行 Android 真机性能、触屏手感及全部车辆在所有机关上的验证；本次生成网页构建资源，未生成新 APK。软件渲染测试结果不能代表手机帧率。
