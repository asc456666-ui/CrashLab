# 生物小岛、高速与飞跃更新

## 新内容

- 新增滨海高速：四车道长直路、左右分岔、跨线立交、双侧上下桥坡道、可撞护栏、十辆巡游车辆及高速飞坡。
- 高速尽头青色光门自动传送到独立小岛。小岛离岛门为金色，直接返回车库。地图不提供直接进岛或离岛的传送捷径。
- 小岛有 32 只动物（鹿、牛、野猪、兔子）、8 只卡通怪兽、27 棵可撞倒树木和成片无碰撞杂草。横纵主路和出生位置避开树干，车辆仍可驶离道路自由碰撞。
- 原地图额外加入 16 个行人、8 辆车辆和 8 只动物。新人口模块共 109 个碰撞角色 / 树木，不计原有城市行人与车辆。
- 人物和动物采用卡通表现，被撞后由刚体运动，巡游暂停，过一段时间在安全距离外恢复；没有血腥表现。
- 扩展至 16 处探索地标，发现记录沿用本机持久化存储。

## 密码规则

1. 首次打开需要密码。
2. 每次进入设置都需要密码；离开再进入也重新验证。
3. Android 生命周期或浏览器页面可见性判断进入后台；每次返回前台均撤销旧授权并重新弹出密码盘。
4. 验证前驾驶输入与物理暂停，设置页隐藏。后台期间提交密码无效。
5. 前台重新验证不重置已用时长；若已经超时，进入家长解锁流程。

## 飞跃与特技

飞坡离地给予一次随速度变化的向上助推，普通山路和停车楼不触发。双击油门的 320 毫秒窗口适用于屏幕按钮和 W / ↑；长按、键盘自动重复和方向键不会触发特技。

特技根据飞行状态自动选择：上升时后空翻、高处接近顶点时螺旋、快速飞行时水平回旋，其余状态侧翻；快速下降可获得每次飞跃一次的喷射跃升。车体碰撞姿态保持可控，整车及轮胎统一做视觉旋转，落地恢复正常姿态。

飞行镜头基于速度方向维持地平线，适度拉远、拓宽视野并随特技绕车；加入彩色拖尾、起飞粒子、边缘速度线、实时腾空时间 / 高度与落地冲击环。落地后结算高度及完成动作数量。

设计参考了 Rockstar 官方资料中的空中特技镜头和起跳速度调节思路，未加入赛事或使用其素材：[官方特技创作指南](https://media.rockstargames.com/rockstargames/img/global/news/upload/GTAO_Race_Creator_Guide.pdf)、[官方特技道具与地形设计建议](https://www.rockstargames.com/newswire/article/9k1248838a42ko/tips-for-creating-stunning-cunning-stunt-races-with-the)。

## 闪烁处理

- 草地、区域铺装、泥地、道路和标线分开高度与深度偏移层。
- 旧地图薄铺装和标线使用独立深度偏移，避免修改共享材质。
- 坡道与平台的交叠面加深度偏移；水池底面不再和大地面重合。
- 相机近裁面从 0.1 调整为 0.3，提高远处地面的深度精度。
- 阴影跟随位置按阴影像素尺寸对齐，减少车体细微晃动引起的阴影闪动；地面纹理启用各向异性过滤。
