# 2026-10-23 修复记录

修复基于版本 87908c5。

1. **退出按钮**：Android 调用 Capacitor App.exitApp；返回键与退出按钮共用流程。网页版停止游戏、保存最高分、释放输入，并提示关闭标签页。
2. **家长锁屏**：后台暂停状态与密码验证状态分别判断。回到前台不会解除家长锁屏，锁屏期间禁止游戏快捷键和驾驶输入。
3. **旧车辆清理**：移除车辆时调用 RaycastVehicle.removeFromWorld，解除物理世界的 preStep 回调，避免反复开始后旧车辆继续更新。
4. **碎块清理**：清理无归属碎块时同时从场景移除网格，释放临时碎块的几何资源；清空、出界和容量回收共用同一清理流程。
5. **零件修复朝向**：脱落前保存局部旋转，修复时恢复原始朝向，覆盖普通碰撞与爆炸两条路径。
6. **低帧率计时**：家长限时累计实际游玩时间，物理模拟继续单独限制每帧步长。
7. **地图还原（按用户要求调整）**：换车、重新开始均保留建筑破坏和道具位置，仅落锤恢复。打开地图后点击底部“重置建筑”，才主动恢复建筑与场地道具，保留当前车辆车损；重复重置不会重复添加。破坏状态保留在本次应用运行中，关闭重开会重新生成地图。
