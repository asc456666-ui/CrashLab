# Crash Lab 碰撞实验场

[English](README_EN.md) | 简体中文

一个给孩子玩的 3D 车辆碰撞模拟。最终交付是 Android APK：安装后完全离线运行，不依赖浏览器、不依赖局域网、不依赖任何服务器，也完全不申请网络权限。

物理效果参考撞车类沙盒游戏的思路，但底层是刚体物理加视觉变形，不是真正的软体物理。目标是在普通中端手机上流畅运行，撞起来反馈明显，操作门槛低到孩子上手就能玩。

## 快速开始

### 玩安卓版

到 Releases 页面下载 CrashLab-release.apk，传到手机，文件管理器点开安装，允许安装未知来源即可。装完断网也能玩。

微信传输会把 apk 后缀改成 apk.1，装不上时把后缀改回 apk。

### 本地跑网页版

网页版只用于开发调试，不是交付物。需要 Node 18 以上。

```bash
npm install
npm run dev
```

手机和电脑连同一个 WiFi，浏览器打开终端打印的 Network 地址就能玩。

### 自己构建 APK

需要 JDK 21 与 Android SDK。在 android/local.properties 里写本机路径：

```properties
sdk.dir=/你的路径/android-sdk
```

然后：

```bash
npm install
npm run build
npx cap sync android
cd android
gradlew.bat assembleDebug
```

产物在 android/app/build/outputs/apk/debug/。要出正式签名包，在 android/ 下建 keystore.properties 填签名信息，用 assembleRelease。

## 家长控制

打开应用第一件事是输入六位密码，没通过之前进不去游戏，也不会计时。

- 初始密码 `456321`，固定不可修改，代码里写死，界面上不提供任何修改入口
- 每次打开应用都要重新输入。授权只存在内存里，关闭重开一定重来一遍
- 游玩时长在设置里选：十五分钟、三十分钟、六十分钟、不限，默认三十分钟
- 改时长要输密码，改完立刻生效
- 玩到设定时长自动锁屏，画面正中出现提示，要密码才能继续
- 解锁之后计时清零，重新开始计
- 时长按真实时间算，慢动作不会缩短计时；停在菜单里也不算

密码忘了只能改代码里的 `INITIAL_PIN` 或者清除应用数据，没有找回入口。这是刻意的，避免被孩子绕过去。

## 控制方式

### 手机

- 左下两个大按钮：左转、右转
- 右下三个大按钮：油门、刹车、手刹
- 右上：翻正、视角、慢放、落锤、重置、菜单
- 坦克出场时，开炮键出现在方向键上方

### 电脑键盘

| 按键 | 功能 |
| --- | --- |
| W 或 上箭头 | 油门 |
| S 或 下箭头 | 刹车，停住后继续按则倒车 |
| A D 或 左右箭头 | 转向 |
| 空格 | 手刹 |
| F | 一键翻正 |
| C | 切摄像机 |
| T | 慢动作，1 倍、0.25 倍、0.1 倍循环 |
| R | 重置修复车辆 |
| X | 坦克开炮，仅坦克可用 |
| H | 触发落锤 |
| Esc | 回菜单 |

拖拽屏幕可以绕车观察，自由视角下才生效。

### 空中特技

- 腾空时按住油门：前空翻
- 腾空时按住刹车：后空翻
- 腾空时按左右方向键：横向翻转，也就是侧滚
- 油门和方向键一起按：螺旋翻转，圈数多了会变成三段螺旋或者疯狂螺旋
- 落地的瞬间按累计转过的整圈数结算特技分，腾空时屏幕下方会浮出按键提示

## 地图分区

- A 区 高速跑道：四百米直道，尽头是混凝土墙和金属护栏，可以一路加速到三百公里撞上去
- B 区 跳台区：小、中、大三个跳台
- C 区 障碍区：水泥墩、金属桶、木箱、石块、路障、减速带，部分能撞飞
- D 区 坠落台：三十米高台，可以开下去自由落体
- E 区 落锤区：点落锤按钮，大金属块砸下来压车顶
- F 区 保龄球道：木质车道加十个三角排布的球瓶
- G 区 砖墙阵：三面砖墙共三十六块砖，可以一块块撞穿
- H 区 波浪连续坡道：六个小坡连成串，最适合练空中特技
- I 区 三百六十度圆环：半径十二米的竖直圆环，高速冲进底部可以沿内壁转一整圈，进环后相机自动换成贴身机位
- J 区 水池：浅水，进去会被拖慢，高速涉水会溅起水花
- K 区 车库：跑道起点旁的停车库，卷帘门收在顶上，可以直接开出去
- L 区 山林：一百三十乘两百四十的丘陵地带，连成片的起伏路面，围绕地面上下起伏约一点五米，坡度平缓，车能一路顺畅开过去，十六棵能撞倒的树，草地不加阻力
- M 区 城市：十字马路加沿街五栋楼，路上有六辆沿路行驶的车、六个来回走的行人，全都撞得飞，楼还能被坦克打塌

出生点十二个，在设置里切换。

## 车损与爆炸

车损不影响动力与极速，撞烂了照样能开。车损只改变外观与状态：

- 车漆随车损加深逐渐发黑，表面越来越粗糙
- 车损过半开始冒烟
- 车损低于三成开始起火，引擎盖持续喷火苗
- 车损归零原地爆炸，火球火花黑烟冲击环一起上，车上零件全部炸飞，动力切断，屏幕正中弹出车辆已报废提示，按重置键才能继续

## 关于翻滚

车不会动不动就翻，靠两件事一起做的。

接地时有一套主动稳定，等效于防倾杆加俯仰阻尼再加一根很硬的回正弹簧，过弯侧倾和撞完乱转都会很快收敛。实测高速转向时车身最大倾角只有四点六度。

空中特技要飞到接近最高点才能做，起跳后前零点四二秒不响应输入。这样飞坡是先把车甩上去，到了高处再翻滚，不会刚上斜坡就栽下来。

---

## 撞击计分

撞得越狠分越高，撞飞能推动的障碍额外加分，一点六秒内连续撞击有连击倍率，最高五连。单个撞击最高一百六十分。

空中特技单独计分：空翻一次二百六十分，侧翻一次二百分，多圈累加。

分数显示在左上角，最佳分自动保存在本地。

## 开发与验证

项目用 Playwright 无头浏览器跑自动化验收，每轮改动都留原始数据在 docs 下。

```bash
node test/verify-star-car.cjs     # 星星小车生成与撞击
node test/verify-round8.cjs       # 翻滚抑制、炮击目标、行人车流
node test/offline-check.cjs       # 断网完整流程验收
```

测试脚本自带静态服务 `test/static-server.cjs`，会自己起在 127.0.0.1，跑完自动关闭，不需要另外开服务器。
