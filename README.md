# 碰撞实验场二代 · Crash Lab 2

[English](README_EN.md) | 简体中文

仓库地址：https://github.com/asc456666-ui/CrashLab

一个给孩子玩的 3D 车辆碰撞模拟。最终交付是 Android APK：安装后完全离线运行，不依赖浏览器、不依赖局域网、不依赖任何服务器，也完全不申请网络权限。

物理效果参考撞车类沙盒游戏的思路，但底层是刚体物理加视觉变形，不是真正的软体物理。目标是在普通中端手机上流畅运行，撞起来反馈明显，操作门槛低到孩子上手就能玩。

## 结论先行

- 交付形态：CrashLab-release.apk，Capacitor 封装，游戏本体随包内置，装完即玩
- 技术栈：Three.js 渲染，cannon-es 物理，Vite 打包，Capacitor 生成 Android 原生壳
- 完全离线：不申请任何 Android 权限，连 INTERNET 都没有，所有资源随 APK 内置
- 强制横屏、沉浸全屏，返回键优先回主菜单，已在主菜单才退出
- 切后台自动暂停物理与音频
- 内容规模：六辆可驾驶车辆，主地图、高速、生物小岛与工地小岛，共二十一个出生点；163 个场景角色与可倒树木，包含 66 辆随机巡游车辆
- 已实现：驾驶、撞击、车身凹陷、零件脱落、轮胎损伤与脱落、玻璃破裂、火花、烟雾、空中特技、慢动作、四种摄像机、一键修复、一键翻正、坦克开炮、撞击计分与连击、起火与爆炸
- 家长控制：打开应用先输密码，可设游玩时长，到点自动锁屏，解锁与改时长都要密码
- 动力与车损解耦：车撞烂了照样能开，车损只影响外观、起火与爆炸
- 极速：红色跑车最高 320 公里每小时，跑道已延长到四百米供助跑

## 自由探索扩建

保留碰撞、城市、山林等原有内容，新增云顶山地、浅湾湿地、采石工地、集装箱港口、天空停车楼、机械游乐谷、滨海高速、生物小岛和工地小岛。主地图区域可自由驶达或使用地图传送；高速尽头左侧青色门前往生物岛，右侧橙色门前往工地岛，离岛金色门直接返回车库。没有赛事、圈数或强制任务顺序。

- **地图**：点击右上角“地图”或按 M；选择区域传送，按 Esc 或“继续驾驶”关闭。地图打开时暂停驾驶与游玩计时。
- **互动**：靠近机关按 E，或点击屏幕出现的互动按钮。可操作吊机、升降台、港口开合桥和维修站。
- **探索**：找到十八处青色圆环地标，发现记录会保存在本机；小地图显示当前位置和发现数量，并对高速 / 两个小岛单独缩放。
- **工地与巡游**：42 辆电动车、三轮车、农用车与工程车辆加入工地岛；所有场景车辆随机选择目标与快慢速度，动物会走、跑、跳跃、坐下或躺卧。
- **漂移**：三款小车中高速带油门持续转弯逐渐侧滑，配有少量轮胎烟雾和距离提示；侧滑过大时恢复抓地，松开方向平滑回正。已去掉遮挡视线的两侧气流，改善高刷新率驾驶平顺性。
- **驾驶**：泥地降低抓地力并增加阻力，浅水产生水花；山路通往 48 米观景台，停车楼侧坡可通往两层平台和屋顶跳台。
- **破坏保留**：换车、重新开始和区域传送不会复原被打毁的建筑或移动的道具。换车 / 重新开始仅恢复落锤。需要恢复场地时，打开地图，点击底部小按钮“重置建筑”；车辆状态保留。完全关闭并重开应用会重新生成地图。

扩建内容与验证范围见 [开放世界扩建记录](docs/OPEN_WORLD.md)。

高速、小岛、生物碰撞与飞跃更新见 [小岛与飞跃更新](docs/ISLAND_FLIGHT.md)。每次进入设置，以及每次从后台返回，都必须重新输入家长密码；后台验证不会清零已经使用的游玩时间。

本轮双岛、随机巡游和漂移的操作与实现见 [工地岛与漂移更新](docs/WORK_ISLAND_DRIFT.md)，操控修正见 [漂移与抖动修复](docs/DRIFT_HANDLING_FIX.md)。二代版本为 2.0.0，发布包见下方。

## 快速开始

### 玩安卓版

到 https://github.com/asc456666-ui/CrashLab/releases 下载 CrashLab-release.apk，传到手机，文件管理器点开安装，允许安装未知来源即可。装完断网也能玩。

当前版本 **v2.0.0 · 碰撞实验场二代**：[下载 APK](https://github.com/asc456666-ui/CrashLab/releases/download/v2.0.0/CrashLab2-v2.0.0.apk)。文件大小 3449780 字节，SHA256 为 `db4773f72827e3ae9b8940b2700a0c651a10c7d25f9daa015b7bd67c00e3915d`。

二代使用独立应用标识，可与一代同时安装。原版发布私钥未在本次环境找到，不能直接覆盖一代；无需卸载一代，其本地数据保留。二代的发布签名保存在本机且不上传仓库。

```powershell
Get-FileHash CrashLab2-v2.0.0.apk -Algorithm SHA256
```

微信传输会把 apk 后缀改成 apk.1，装不上时把后缀改回 apk。

### 本地跑网页版

网页版只用于开发调试，不是交付物。需要 Node 18 以上。

```bash
npm install
npm run dev
```

手机和电脑连同一个 WiFi，浏览器打开终端打印的 Network 地址就能玩。

### 自己构建 APK

需要 JDK 21 与 Android SDK。在 android/local.properties 里写本机路径：

```properties
sdk.dir=/你的路径/android-sdk
```

然后：

```bash
npm install
npm run build
npx cap sync android
cd android
gradlew.bat assembleDebug
```

产物在 android/app/build/outputs/apk/debug/。要出正式签名包，在 android/ 下建 keystore.properties 填签名信息，用 assembleRelease。

## 家长控制

打开应用第一件事是输入六位密码，没通过之前进不去游戏，也不会计时。

- 初始密码 `456321`，固定不可修改，代码里写死，界面上不提供任何修改入口
- 每次打开应用都要重新输入。授权只存在内存里，关闭重开一定重来一遍
- 游玩时长在设置里选：十五分钟、三十分钟、六十分钟、不限，默认三十分钟
- 改时长要输密码，改完立刻生效
- 玩到设定时长自动锁屏，画面正中出现提示，要密码才能继续
- 解锁之后计时清零，重新开始计
- 时长按真实时间算，慢动作不会缩短计时；停在菜单里也不算

密码忘了只能改代码里的 `INITIAL_PIN` 或者清除应用数据，没有找回入口。这是刻意的，避免被孩子绕过去。

## 控制方式

### 手机

- 左下两个大按钮：左转、右转
- 右下三个大按钮：油门、刹车、手刹
- 右上：翻正、视角、慢放、落锤、重置、菜单
- 坦克出场时，开炮键出现在方向键上方

### 电脑键盘

| 按键 | 功能 |
| --- | --- |
| W 或 上箭头 | 油门 |
| S 或 下箭头 | 刹车，停住后继续按则倒车 |
| A D 或 左右箭头 | 转向 |
| 空格 | 手刹 |
| F | 一键翻正 |
| C | 切摄像机 |
| T | 慢动作，1 倍、0.25 倍、0.1 倍循环 |
| R | 重置修复车辆 |
| X | 坦克开炮，仅坦克可用 |
| H | 触发落锤 |
| Esc | 回菜单 |

拖拽屏幕可以绕车观察，自由视角下才生效。

### 空中特技

- 冲过飞坡会获得一次起飞助推，普通行驶坡道不进行助推。
- 空中快速点两下油门（键盘 W / ↑ 或屏幕油门键，间隔不超过 320 毫秒），自动根据上升、顶点、下降和速度选择特技。
- 可触发云端后空翻、天空螺旋、疾风回旋、流星侧翻和一次喷射跃升；按住油门及方向键不再自动翻转。
- 飞行镜头沿运动轨迹跟随并适度绕车，配合视野拉开、拖尾、速度线和着陆冲击环。
- 完成动作并落地后结算飞跃高度和特技分。

## 车损与爆炸

车损不影响动力与极速，撞烂了照样能开。车损只改变外观与状态：

- 车漆随车损加深逐渐发黑，表面越来越粗糙
- 车损过半开始冒烟
- 车损低于三成开始起火，引擎盖持续喷火苗
- 车损归零原地爆炸，火球火花黑烟冲击环一起上，车上零件全部炸飞，动力切断，屏幕正中弹出车辆已报废提示，按重置键才能继续

## 关于翻滚

车不会动不动就翻，靠两件事一起做的。

接地时有一套主动稳定，等效于防倾杆加俯仰阻尼再加一根很硬的回正弹簧，过弯侧倾和撞完乱转都会很快收敛。实测高速转向时车身最大倾角只有四点六度。

空中特技要飞到接近最高点才能做，起跳后前零点四二秒不响应输入。这样飞坡是先把车甩上去，到了高处再翻滚，不会刚上斜坡就栽下来。

---

## 撞击计分

撞得越狠分越高，撞飞能推动的障碍额外加分，一点六秒内连续撞击有连击倍率，最高五连。单个撞击最高一百六十分。

空中特技单独计分：空翻一次二百六十分，侧翻一次二百分，多圈累加。

分数显示在左上角，最佳分自动保存在本地。

## 开发与验证

项目用 Playwright 无头浏览器跑自动化验收，每轮改动都留原始数据在 docs 下。

```bash
node test/verify-star-car.cjs     # 星星小车生成与撞击
node test/verify-round8.cjs       # 翻滚抑制、炮击目标、行人车流
node test/offline-check.cjs       # 断网完整流程验收
node test/release-check.cjs       # 对发布 APK 内的资源做离线验收
```

测试脚本自带静态服务 `test/static-server.cjs`，会自己起在 127.0.0.1，跑完自动关闭，不需要另外开服务器。

`release-check.cjs` 比较特别：它先把签名包里的资源解到临时目录，加载完了再切断网络，用来确认发布出去的那一版真的不依赖外部域名。改打包配置之后建议跑一次。
